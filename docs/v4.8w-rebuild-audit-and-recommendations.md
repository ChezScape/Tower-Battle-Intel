# v4.8w Rebuild Audit and Recommendations

## Code fighting removed

1. History filters now have one delegated handler system. The old native/select compatibility path was removed from the live handler flow.
2. Subsystem Matrix clicks no longer perform forced `scrollTo()` calls. The panel updates in place and restores the current viewport.
3. Desktop and mobile CSS were rebuilt cleanly, rather than adding more override blocks to the old files.
4. The old unused debug placeholder and unused scaffold files were removed from the full project.

## Kept intentionally

- `src/game/` stays because the game knowledge files are now the best route for improving the tool brain.
- `inspectionPanel.js` stays as the active debug system.
- `style.css` stays as a short note only and is not loaded.

## Modernisation recommendations

1. **Create a Design Token file later**: move colours, spacing, radii, and shadows into a small shared config or generated CSS variables block.
2. **Card priority system**: let Compare / Systems / Coach mark items as Primary, Secondary, or Detail, so mobile can show less by default.
3. **Game Brain expansion**: keep feeding `src/game/metricCatalog.js`, `enemyCatalog.js`, and `interpretationRules.js`; avoid hardcoding game knowledge in UI files.
4. **Saved layouts**: add a future setting for compact, balanced, and detailed layout modes.
5. **Banner set**: current 4:1 desktop and 3:1 mobile banners are suitable. If remade later, generate them as true header images only, not tall poster art.
6. **History virtualisation**: if history grows beyond 100+ runs, render visible cards only to keep mobile fast.
7. **Command Deck polish**: keep it top-opening on mobile, then add import/export as a secondary drawer instead of adding more buttons to the main screen.

## Testing focus

- Desktop: Subsystem Matrix click should not move the page.
- Mobile: bottom tabs should switch without flicker.
- History: typing in search should keep your position and cursor.
- Debug: hold banner, open panel, check version pill and output scroll.
