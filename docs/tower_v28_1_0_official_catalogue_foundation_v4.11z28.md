# The Tower v28.1.0 — Official Catalogue Foundation for TBI

This document summarises the useful project-wide data extracted from the uploaded XAPK and converted into TBI catalogues.

## Highest-value catalogue areas

1. Enemies and death causes
2. Ultimate Weapons and source rows
3. Cards and card masteries
4. Workshop upgrades
5. Labs/research
6. Tournament Heat and leagues
7. Guardian and loot/shards
8. Modules and module resources
9. Bots
10. Perks and trade-offs
11. Resources/economy sources
12. Missions/events/relics

## What this helps

- Better Battle Report parser aliases
- Better History grouping/search
- Better Systems glossary
- Better Command Deck wording
- Better Debug catalogue health checks
- Safer future Compare rebuild

## What it does not do

- No exact hidden formulas
- No server/tournament live values
- No gameplay automation
- No graph rebuild
