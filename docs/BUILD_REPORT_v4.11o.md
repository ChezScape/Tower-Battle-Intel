# Tower Battle Intel v4.11q — Desktop Advantage Meter

Build folder: `Tower-Battle-Intel_v4.11q_DesktopAdvantageMeter_FullBuild`

## Scope

Desktop-only polish pass. Mobile CSS was left untouched.

## Changes

- Updated runtime version to `v4.11q`.
- Replaced the copied progress-bar style on major metric cards with a centre-split A/B advantage meter.
- Positive panel totals now fill from the centre toward the B side.
- Negative panel totals now fill from the centre toward the A side.
- Neutral panel totals keep a small centre marker.
- Kept the `DIFF+` modal behaviour from v4.11n.
- Kept the v4.11j/v4.11k/v4.11l colour and card hierarchy work.
- Did not change mobile CSS.

## Reason

The old bars looked like generic progress bars and most cards appeared visually identical. The new meter is intended to explain direction and advantage more clearly without changing card size.
