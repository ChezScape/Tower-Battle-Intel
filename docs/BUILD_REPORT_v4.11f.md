# Tower Battle Intel v4.11g - Desktop Small Window Fit Polish

## Scope
Desktop-only dashboard fit pass based on v4.11g. Mobile CSS was not changed.

## Goals
- Preserve the v4.11g maximised and medium-window layout.
- Stop small desktop windows from crushing the right rail into unreadable panels.
- Keep the Concept 5 desktop style, cyan/gold run trim, VS styling, and metric art.
- Use deliberate compact desktop behaviour instead of mobile-style stacking.

## Changes
- Added narrow-desktop rules that move side intel below the main dashboard at small desktop widths.
- Added compact side-intel card sizing so text no longer overlaps/cuts in small desktop windows.
- Added a very narrow desktop mode that stacks side intel cards and shrinks the top strip safely.
- Added compact Quick Actions layout for narrow desktop windows.
- Updated version to v4.11g.

## Rollback
Use v4.11g if the small-window behaviour is worse on Andrew's desktop setup.
