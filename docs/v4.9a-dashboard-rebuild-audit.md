# v4.9a Dashboard Rebuild Audit

## Purpose

This build replaces the old stacked dashboard UI with the chosen neon concept direction:

- Desktop: wide A vs B comparison console with right-side takeaways, insights, anomalies, and quick actions.
- Mobile: locked app-style layout with top analysis tabs: Dashboard, Compare, Systems, Coach, More.
- Mobile bottom destinations: Dashboard, History, Command Deck, Settings.

## Code fighting removed

## Behaviour changes

- Desktop and mobile render different workspace shells instead of rendering both and hiding one with CSS.
- Desktop CSS contains no mobile-specific rules.
- Mobile CSS contains no desktop-specific rules.
- Subsystem Matrix tiles toggle details in place.
- The old visible banner/header structure was removed from `index.html`; the app header is now rendered by the dashboard.
- Hidden debug hold is delegated to the live header using `data-debug-hold-zone`.
- Command Deck is now a real workspace tab on desktop and remains a top-opening deck on mobile.
